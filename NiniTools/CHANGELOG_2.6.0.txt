NiniTools 2.6.0

[중요몹 「!」 표시 · 고급형 (새 기본)]
- 새 스타일 「고급형」을 넣고 기본으로 바꿨습니다.
  - 그림: 위가 둥글고 아래로 가늘어지는 입체 느낌표 + 둥근 점 (전용 그림 Media/ImportantAlert_Premium.tga)
  - 색: 빨강 ↔ 주황을 0.5초마다 오갑니다 (노랑까지 가지 않음).
  - 크기: 시전 중에는 크기가 그대로입니다 (숨쉬기·박동 없음).
  - 나타날 때: 2.2배 크기로 반투명하게 나타나 0.14초 만에 제자리로 내려앉습니다.
  - 사라질 때: 시전이 끝나면 0.15초 동안 절반 크기로 작아지며 사라집니다.
- 예전 기본(기본형)을 쓰던 사람은 한 번만 고급형으로 바뀝니다. 설정 → Interrupt & M+ → 중요몹 표시 → 표시 스타일에서 기본형·펄스형·강조형으로 되돌릴 수 있습니다 (그 셋은 예전과 똑같음).
- 표시 위치에 「이름표 왼쪽」이 생겼습니다 (체력바·시전바 왼쪽 옆). 기존 위치(머리 위 등)는 그대로입니다.
- 설정 화면의 스타일 카드·미리보기도 고급형 그림과 움직임으로 보입니다.

[버전]
- TOC / Core 2.6.0.

[업데이트]
- 게임 종료 후 Interface\AddOns\NiniTools 폴더만 교체하세요 (새 그림 파일이 있어서 /reload 말고 게임을 껐다 켜야 보입니다).
- 기존 NiniToolsDB(WTF)는 지우지 마세요.

[게임에서 확인할 것]
1. 쐐기에서 중요 시전 → 「!」가 크게 나타났다가 제자리 · 빨강↔주황 · 시전 끝나면 작아지며 사라지는지
2. 표시 위치 「이름표 왼쪽」 → 체력바 왼쪽 옆에 붙는지 (이름표 애드온마다 위치가 조금 다를 수 있음)
3. 크기 슬라이더 70~140%로 바꿔 보기

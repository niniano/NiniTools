NiniTools 2.5.3


[미니맵 아이콘]
- 미니맵 아이콘을 메인 창 오른쪽 설정 버튼과 같은 두 줄 N으로 바꿨습니다 (작은 크기용으로 선만 굵게).
- 미니맵 버튼의 어두운 바탕 칸과 직업색 덧칠을 없애고 아이콘이 버튼을 꽉 채웁니다. 마우스를 올리면 살짝 밝아집니다.
- Gold 버튼도 같은 아이콘을 씁니다 (NiniTools_Minimap.tga 공유).

[기준]
- 2.5.2 BRAND-FIX(워드마크·Round 설정 버튼·Minimap 아이콘) 위에 메모 캡처를 합쳤습니다. 브랜딩 변경은 그대로입니다.

[공대 메모 캡처 · 신규]
- Modules/NSRT/NoteCapture.lua 추가 (TOC: NSRTImport.lua 다음).
- 기본값 꺼짐. /nini memo on 으로 켠 캐릭터만 NiniToolsDB.modules.noteCapture 에 저장합니다.
- NSRT_REMINDER_CHANGED(NSAPI.RegisterCallback)로 공유 메모를 받으면 「받음」 기록 (공대장 이름 포함). 같은 메모를 다시 받으면 기록하지 않습니다.
- ENCOUNTER_START 마다 「풀」 기록: 보스 ID·이름·난이도·인원 + 그때 켜진 NSRT 공유 메모(NSAPI:GetReminderString) + MRT 메모(VMRT.Note.Text1).
- ENCOUNTER_END 마다 「종료」 기록 (성공 여부).
- 메모 본문은 해시 키로 한 번만 저장하고 기록에는 키만 남깁니다. 메모 80개 · 기록 600개를 넘으면 오래된 것부터 지우며, 남은 기록이 가리키는 메모는 지우지 않습니다.
- 시각은 date("%Y-%m-%d %H:%M:%S") (전투 로그와 같은 PC 시계). 분석기가 트라이 시작 시각과 맞춥니다.
- NSRT 가 없거나 API 가 바뀌어도 오류 없이 넘어갑니다 (모든 호출 pcall). 전투 중에는 해시 1번·표 추가 1번만 합니다.
- 비밀 값(issecretvalue)은 저장하지 않습니다.

[명령]
- /nini memo · on · off · clear (켜기/끄기/지우기 한글도 가능). on 할 때 지금 켜진 메모를 한 번 남깁니다.

[버전]
- TOC / Core 2.5.3. SmartRemindersProfile PROFILE_VERSION 은 2.5.2 그대로 (시드 버전과 별개, 재시드 없음).
